# spotify-dj

An MCP server that lets Claude search Spotify, build playlists, and control playback.

## Setup

1. Clone the repo:

   ```bash
   git clone https://github.com/ronakrupani/spotify-dj.git
   cd spotify-dj
   ```

2. Create and activate a virtual environment (Python 3.10+):

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Copy the example env file and fill in your Spotify app credentials:

   ```bash
   cp .env.example .env
   ```
